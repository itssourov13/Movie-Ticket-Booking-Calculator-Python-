# 🎬 Movie Ticket Booking Calculator

A simple Python project that calculates movie ticket prices based on user conditions like age, seat type, show time, membership, and discounts.

---

## 🚀 Features
- 🎟️ Ticket price calculation system
- 🎂 Age-based eligibility check
- 💺 Seat type pricing (Normal / Gold / Premium)
- 🕒 Show time logic (Evening / Regular)
- 🎁 Membership discount system
- ⚠️ Extra charges calculation
- 💰 Final price generator

---

## 🛠️ Built With
- Python 🐍
